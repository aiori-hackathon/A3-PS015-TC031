## Project Overview

This project aims to develop a network diagnostic tool that helps users identify common home and last-mile internet connectivity issues, including gateway reachability problems, DNS failures, packet loss, and network congestion. It analyses network measurements and provides understandable explanations of possible causes, supported by measurable evidence, while reporting inconclusive results when the available evidence is insufficient.

## Proposed Solution

- Develop a user-friendly interface for running diagnostic tests and viewing results.
- Analyse network measurements such as reachability, DNS responses, latency, and packet loss to identify possible connectivity issues.
- Provide transparent, evidence-based explanations and recommendations, reporting inconclusive results when the available evidence is insufficient.
